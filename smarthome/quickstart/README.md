# Smart Home Quickstarts

The `smarthome/quickstart/` directory contains condensed deployment and configuration guides for Home Assistant OS, Matter, Thread, ESPHome, local device integrations, voice infrastructure, and segmented IoT networks.

## Home Assistant and Network Architecture

* [Home Assistant OS on Proxmox](haos-proxmox-deploy_quickstart.md) - Quick deployment of Home Assistant OS as a virtual machine on Proxmox VE.
* [Matter over Segmented Wi-Fi](ha-matter-segmented-network_quickstart.md) - Quick configuration of Matter across segmented Home Assistant and IoT networks.
* [Aqara H2 Matter-over-Thread](aqara-h2-haos-mot_quickstart.md) - Quick deployment of the Aqara Light Switch H2 US using Matter-over-Thread and an external OpenThread Border Router.
* [Home Assistant External SSH](haos-ssh-external-access_quickstart.md) - Quick configuration of direct external SSH access to Home Assistant OS.

## ESPHome and Local Device Integrations

* [ratgdo Chamberlain ESPHome](ratgdo-chamberlain-esphome_quickstart.md) - Quick setup of a local Chamberlain garage-door integration using ratgdo, ESPHome, and Home Assistant.
* [Tapo H100 Doorbell Integration](tapo-h100-haos-doorbell_quickstart.md) - Quick setup of a Home Assistant-controlled doorbell using a GoveeLife button and Tapo H100.
* [Google Nest Device Access](google-nest-device-access-with-haos_quickstart.md) - Quick setup of Google Nest Device Access with Home Assistant OS.

## Voice Infrastructure and EchoMuse

* [Echo Dot 2 Voice Satellite](echo-dot2-haos_quickstart.md) - Quick setup for repurposing an Amazon Echo Dot 2 as an EchoMuse-based local Home Assistant voice satellite.
